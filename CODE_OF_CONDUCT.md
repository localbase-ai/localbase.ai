# Code of Conduct

## The short version

Be decent to people. Assume good faith. Argue about the code, not the person writing it.

## What's expected

- Give feedback on the work, with a reason attached. "This leaks a file handle" is useful;
  "this is bad" is not.
- Accept feedback the same way. Someone finding a bug in your patch is the process working.
- Respect that contributors have different experience levels, time zones, and amounts of
  time to give. Nobody here owes anyone a response on a deadline.

## What's not

- Personal attacks, insults, or derision.
- Harassment of any kind, public or private. This includes unwelcome attention, slurs, and
  deliberate misgendering.
- Publishing someone's private information without their explicit permission.
- Sustained disruption of discussions, issues, or reviews.

## Scope

This applies in every project space — issues, pull requests, discussions, commit messages,
and any place someone is representing the project publicly.

## Reporting

Report conduct issues privately to the maintainers at **<CONDUCT_CONTACT>**. Reports stay
confidential. Maintainers will respond as promptly as they can, which for a project this
size means days, not hours.

Maintainers may remove comments, close issues, or block accounts that violate this
document. Anyone who reports in good faith will not face retaliation.

Security vulnerabilities are a separate process — do not report those here. Use
[GitHub's private vulnerability reporting](https://github.com/localbase-ai/localbase.ai/security/advisories/new).
