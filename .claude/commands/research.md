Research a topic thoroughly using web search and store findings in the project.

## Instructions

1. Take the user's research topic from $ARGUMENTS
2. Use web search to gather comprehensive information:
   - What is it? (product/company/concept description)
   - How does it work? (process, technology, mechanics)
   - Pricing and economics (costs, margins, revenue model)
   - Competitive landscape (alternatives, comparisons)
   - Key players, market size, trends
   - Risks, unknowns, and red flags
3. Write a structured research summary to the appropriate project folder as `research/<topic-slug>.md`
4. Include source URLs where possible
5. Flag what couldn't be found or needs verification
6. End with recommended next steps (calls to make, data to gather, decisions needed)

If no project folder is specified, ask where to store the output.
